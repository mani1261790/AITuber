# 唇の視認性・長袖内の肌貫通対策 v10

## 変更

- 唇の47頂点に、顔UVで範囲を限定した赤みのある頂点色を付与。顔テクスチャ、表情モーフ、骨、瞳、肌の他の部分は変更しない。MToonの頂点色無視を該当顔材質だけ解除し、現在のThree.jsのRGBA頂点色との互換性をRGB参照で修正。
- 長袖に覆われた上腕・前腕の肌1752三角形を描画対象から外す。手・手首の三角形、全ての頂点座標・ウェイト・表情モーフは保持。袖メッシュを大きくしたり、ポーズを制限して隠す対策ではない。長袖専用なので、袖なし衣装へ変更する際はv9等の元データを使用する。
- 長髪20関節に対する胴体ガードを衣装の厚みに合わせて拡張。上腕・前腕に追従するカプセル4個を追加し、計8個に。髪の剛性・重力・減衰は変更しない。
- 講義の既定モデル、モーションラボの既定・VRMAプレビューをv10へ更新。v9も比較選択できる。
