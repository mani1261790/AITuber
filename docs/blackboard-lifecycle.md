# 板書の保持と消去

教材スライドと黒板の板書は別の表示状態として保持する。新しいUnitやスライド画像の到着だけでは黒板を差し替えない。

授業の `drawing` アクションは次の順で実行する。

1. スクリーンが出ていれば、紐を引いて戻す。
2. 前の板書が残っていれば、その内容のある範囲へ移動し、黒板消しで拭く。空の黒板では省略する。
3. 拭いた範囲だけ古い板書を消す。消去と教具の軌道は共通のピクセル座標から計算する。
4. 新しいMarkdown/TeXを順に表示し、書く動作を行う。
5. 完了通知後に立ち位置を戻し、説明へ進む。

書き換え途中に別のアクションへ変わっても、実際に表示されている途中の板書を保持する。次の板書はその状態から消去する。表示中のスクリーンの裏でも板書は保持する。

`StagePropMotion` は通常2か所（広い板書では4か所）の立ち位置と手の往復を担当する。拭く動作は8ストローク・合計6.8秒。移動時間は別に必要で、移動中は消去時間を進めない。`board-erase.ts` の軌道を黒板消しの位置と画像マスクの両方で使う。授業側の既存の進捗通知と完了待ちを利用し、消去中に読み上げを開始しない。

確認はモーションラボの「高校数学」「大学数学」「歴史」から、一度板書を終えた後「消して書き直す」で行える。これは授業と同じ `LessonStage` を利用するが、音声再生・ライブLLM接続の検証ではない。
