# 教材編集・教材一覧 UI の改善

## 変更

- 黒板の編集をスライド直下へ配置。複数の台本がある場合は番号で対応を示す。
- カード右上は個別の開閉。全カードの開閉、左ハンドルのドラッグ、上下キーでの並べ替えに対応。
- 練習問題に `introductionText`（最大600文字）を追加。旧パッケージには回答形式別の既定案内を使用。公開時に案内文の読みも準備する。
- 問題表示時に案内音声を流し、再生完了後も回答待ちを継続。早い回答は案内を中止し、次の発話と重ねない。一時停止・再開に対応。
- 入力後1.8秒で下書き保存。保存中も入力可能。編集世代を比較して、新しい入力を古いレスポンスで上書きしない。保存失敗時は入力を保持し、自動再試行の連打をせず手動で再保存できる。
- 「今すぐ保存」、Cmd/Ctrl+S、「確認して公開」を分離。
- 教材一覧は教材ごとのカードに整理。レベル・時間・公開状況・学習目標と、編集／講義準備をまとめる。
- 講義アイコンの再生三角形をスクリーン内の座標で定義。
