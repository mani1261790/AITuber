# セルフホスト配布 受入記録 — 2026-09-14

Issue #19のセルフホスト配布を、Git管理外の一時データ領域とプロダクション用静的ゲートウェイで検証した。

## 検証環境

- macOS 27.0 (26A428)、arm64
- Node.js 22.14.0
- pnpm 10.7.0
- SQLiteはローカルAPFS上の一時ディレクトリ
- LLMは未接続、TTSは100msの固定テスト音

## 自動受入結果

`pnpm verify:self-host`で次を一度の実行として確認した。

1. ビルド済みAPI、運営画面、教室画面が一時ポートで起動する。
2. APIと運営画面は127.0.0.1に閉じ、教室画面は設定したLANホストだけにbindする。
3. 教室ゲートウェイへ偽の`x-aituber-surface: operator`を送っても運営APIが403になる。
4. 運営画面が起動時設定から正しい教室URLを取得する。
5. 教室ゲートウェイのWebSocketから初期スナップショットを受信する。
6. 二次関数、DNA複製、VAE再パラメータ化の3教材について、開始、匿名参加、再接続、確認問題の正答、全Teaching Unit完了まで進む。
7. サーバー稼働中にSQLiteオンラインバックアップを作る。
8. バックアップにLLM設定の秘密値と再生成可能なTTSキャッシュが入らない。
9. 稼働中の復旧を拒否する。
10. manifestにないファイルを加えたバックアップの復旧を拒否する。
11. サーバー停止後に別データ領域へ復旧し、DBのSHA-256と作成教材の内容がバックアップと一致する。

結果: 合格。

## クリーン導入

Git管理ファイルだけを新しい一時ディレクトリへ展開し、依存やビルド成果物がない状態から次を実行する。

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm verify:self-host
```

07:48 JSTに、`node_modules`、全`dist`、`.data`、`.env`、TypeScript増分キャッシュを除いた一時ディレクトリで実行した。pnpmはlockfileを変更せず155パッケージを導入し、全9 workspaceのビルドと3教材のセルフホスト受入に合格した。

## 境界確認

- 秘密設定と永続データは`AITUBER_DATA_DIR`および外部envファイルでGit checkout外へ配置できる。
- 更新対象はGit管理ファイル、依存、ビルド成果物に限られる。
- バックアップは秘密設定と再生成可能キャッシュを含めず、manifestで完全性を確認する。
- 外部公開時のTLS・認証は運営・教室ゲートウェイの前へ接続する。APIは引き続きループバックに閉じる。
