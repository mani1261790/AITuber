# スライドと台本を対にしたパッケージ編集

## 変更

- 教材の授業順で左にスライド、右に台本を縦に配置。800px以下ではスライド→台本の順。
- 「スライド・台本」「練習問題」の2タブ。読み方タブと単元選択の内部サイドバーを廃止。
- PDFは同じ元資料を1度取得し、近くのページのみcanvas描画。ネイティブPDFビューアを使わない。
- 台本の読みをruby/rtで表示。編集記法は `｜原文《よみ》`。区切り文字を文字として扱う際はバックスラッシュでエスケープする。Windowsパスなど区切り文字以外のバックスラッシュは保持する。
- 原文と読みは構造化して保存し、記法を読み上げ本文へ入れない。手動修正は発音指定として保持する。本文変更で不足した読みは公開時にまとめて再生成する。未変更多数の文を再生成しない。
- 変更前revisionの一致を確認して保存。削除済みの発話は読み審査から除外。既存の下書き/公開分離と授業版固定を維持。

## 確認

ローカルの実HTTP APIとPlaywrightで、17項目の表示、タブ切替、PDF取得1回、390px幅でscrollWidth=390、ルビ修正→保存→再読込を確認。ローカルの教材台本はUI検証用fixtureであり、実AI審査ではない。

本番のOllama教材では既存のChatGPT接続を使い、台本と読みの準備・公開を別途実行して検証する。実行前に講義がFINISHEDであることと保護停止がないことを確認した。
