# 教具操作モーションの試作

モーションラボの「教具の動作（試作）」で比較する。

- 黒板に書く：黒板前へ移動し、背を向け、左手で座標軸と曲線を試し書きする。線の間はペンを離して移動し、終了後は客席へ向き直る。
- スクリーンを引く：右端へ移動してひもを引く動作と白い投影面の下降を同期する。
- 自動で降ろす／スクリーンを戻す：既存の巻き取りアニメーションとの比較。

到着・方向転換が完了するまで描画・下降を開始しない。腕は既存の姿勢補間・IKを経由し、動作終了時に重みを落として待機へ戻す。黒板の線は投影教材とは別のテクスチャである。

## 範囲と残件

これはラボ内の固定図による試作。授業進行やSVGツールとの自動接続、任意文字の筆順生成は未実装。チョークの軌跡は目標点に基づくため、モデル体型・腕の可動域・姿勢補間によって指先とずれる場合がある。ひもの握りとチョークの指接触を含め、実用化前にさらに調整が必要。低モーション設定では教具操作の手動試作より自動スクリーン操作を使用する。

## 検証

到着待ち、終了時の解放、再実行、線間の手先連続性（30/60/120fps）、同じ立ち位置で黒板と客席へ向き直る動きをテスト。ローカル実画面で試し書き、白いスクリーンの下降・終了姿勢を確認した。接触の厳密な一致や衣装干渉の完全解消を保証するものではない。

## 2026-10-11 書字とひも操作の再設計

書字は大きい座標軸・放物線の手先軌跡を廃止。約7.5cmの短い横線・縦線・払いを組み合わせ、字間の移動と改行、筆先を浮かす動き、小さな手首回転を加えた。黒板への描画は行わない。

ひもを実際の指位置へ追従させる処理も廃止した。リングは固定された垂直経路を持ち、到着→手を伸ばす→掴む→下へ引く→離す→ひもが戻る／腕を体側へ下ろす→待機の順で動く。スクリーンは下降位置で止まる。手側で指の長さを含めたIKを解き、掴んでいる間だけ姿勢補間後にも接触を補正する。リングを手へ吸い寄せて接触誤差を隠さない。

## 2026-10-11: 巻き戻しと板書の連携

- `screen-up`：リングを短く引く→離す→スクリーン格納→腕を下ろす。リングは独立した垂直軌道。
- 書字要求時にスクリーンが出ていれば、この格納動作を先行させる。
- 書字は持ち上げた復帰ストロークを挟んでループ。板書表示時間または明示的な完了通知で終了。
- 授業のdrawingフェーズと接続。板書ラスタライズ、文字単位の表示、腕の解放を待って完了通知する。
- 背面から戻った際の移動完了判定は角度を正規化し、±2πを同じ向きとして扱う。
