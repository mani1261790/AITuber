# 教室の表示とモーション

- 講義ステージは16:9。ヘッダーは42px、右側はコメント欄とし、ページ全体はスクロールさせない。コメント履歴・確認問題・授業結果は各領域内でスクロールする。
- 通常は教材を白い投影スクリーンに表示する。黒板は独立した補足メモで、ライブ補足のパッチ・補足文・訂正のみを表示する。メモがないときは空の黒板。ライブ補足中はスクリーンを収納し、通常教材へ戻ると展開する。手動でも切り替えられる。
- 黒板の面・枠、投影シート・収納部、床・壁、VRMキャラクターは同一のThree.jsシーンとカメラで描画する。
- 教材と補足メモは別の内容から1280×720で画像化し、それぞれスクリーンと黒板のテクスチャに使う。画面リサイズでは改行や配置を再計算しない。現段階ではクライアントで画像化し、授業前の画像ファイル保存は行わない。
- スクリーンは指数補間で上から展開・収納する。UVを調整し、展開途中でも教材の文字を縦に押しつぶさない。動きを減らすOS設定では即時切り替えする。
- ウィンドウの幅が高さを下回ったら、PCでも講義上・コメント下に切り替える。同じ幅でも縦横比によって配置が変わる。
- 字幕は初期OFF。表示時の背景は rgba(18,20,37,0.6) とする。
- 質問先は初期状態「指定なし」。教材画像のクリック（3Dのレイキャスト）、または選択欄で任意に指定できる。未指定でも送信可能。サーバーでは既存の質問処理との互換性のため表示シーンの先頭対象を文脈として補う。
- 「わかった」「もう一度」の専用ボタンは置かず、コメント欄に入力する。
- 確認問題と選択肢はTeX区切りと既存教材の単純な数式表記を描画する。任意の自然言語からすべての数式を推定するものではない。
- キャラクターは教材の切り替え時も保持する。注目先の画面座標から腕の仰角を求め、指数補間で姿勢を移行する。呼吸、顔の動き、まばたき、発話時の口形、髪と衣装の揺れを組み合わせる。
- 教材を大きく見せる寄りのカメラを使い、両足の低い方を床の高さに合わせる。指示対象の画像内の位置に応じて左右へ移動し、対象がないときは中央へ移動する。腕振り、脚・膝・足首の周期動作と移動速度を連動させる。指差しは休止を挟み、待機時も呼吸・視線・腕を動かす。
- 現在の歩行と指示動作は手続き的モーション。モーションキャプチャのクリップ、足の接地点を固定するIK、指先を対象位置に正確に接触させるIK、チョークで文字を書く動作は含まない。

確認: 教室で上下の対象変更、黒板／投影切り替え、字幕OFF→ON、確認問題の平方・座標の表示を確認。クライアントのテスト・型検査・ビルドを実行する。
