# 台本と同時に生成する板書

黒板の新規生成にSVG専用モデルを使わない。ローカルとCloudflareの両方で、SVG環境変数が残っていても授業サービスから呼び出さない。過去に保存済みのSVGは表示互換のため読み取れる。

授業中のUnit台本の各beat、およびライブ補足の生成結果に `blackboardMarkdown` を含める。文字列なら黒板を全面更新して説明し、nullならスライドを使う。台本と別の画像生成APIは呼ばない。板書の表示完了を待って発話し、次のスライドbeatでスクリーンへ戻す。

## 最小記法

```markdown
# 平方完成
◎ **同じ値を足して引く**
$$x^2-4x+3=(x-2)^2-1$$
→ 頂点は $(2,-1)$
→ 軸は $x=2$
```

- `#` / `##`：見出し
- 改行：板書の行。`-` / `*` の行頭箇条書きは「・」になる。
- `**強調**`：黄色の強調
- `◎`、`→`などの文字をそのまま表示
- `$...$`、`$$...$$`：TeX。数式ブロックも一行で指定する。

最大8非空行、各行80文字、全体700文字。HTML・画像・リンク・コードブロックは受け付けない。板書専用の余白内で全体を等倍縮小し、行や数式を途中で切らず、スクロールさせない。投影教材と板書は別のテクスチャとして保持する。長すぎる出力は台本生成の既存フォールバック、補足では既存の再試行／保留へ回る。

## 動作との分離

モーションラボの「黒板に書く」は後ろを向いて書く仕草だけ。黒板を消したり、線・文字・図を追加したりしない。板書内容の表示と手の軌跡は同期描画しない。ラボの仕草を授業進行へ自動接続する処理は今回追加していない。

スクリーンのリングは到達可能な高さから決まった垂直経路を動く。手側をIKでリングへ合わせ、ひもが手を追いかける方式は使わない。離した後は腕を体側へ下ろし、ひもだけが戻る。握る／離す際は接触制約を補間する。

## 検証

同時生成とスライド復帰、補足の審査・待機・本編復帰、TeXと記号表示、文字量制限、描画しない書字動作、指とリングの一致を自動検証。3D教室で板書の実表示と教具操作をローカル確認。生成内容の教科ごとの品質や実LLMの遅延は、この固定応答テストとは別に評価する。
